# 🏋️ Planilha de Treino

Um projeto que fiz para anotar e organizar meus treinos de academia de forma simples e prática. 💪

## 📋 Sobre o projeto

Criei essa **planilha de treino** para facilitar o registro dos meus exercícios, séries, repetições e cargas, deixando tudo organizado em um só lugar.

A ideia é poder consultar meus treinos pelo computador ou celular 📱 e acompanhar o que estou fazendo durante os treinos.

## ⚙️ Funcionalidades

* 🏋️ Anotar exercícios
* 📑 Organizar os treinos
* 🔢 Registrar séries e repetições
* ⚖️ Registrar cargas
* ✏️ Editar informações dos exercícios
* 👀 Consultar os treinos de forma simples
* 📱 Interface adaptada para celular

## 💻 Tecnologias

* 🌐 HTML
* 🎨 CSS
* ⚡ JavaScript
* 📦 Capacitor
* 🤖 Android

## 🎯 Objetivo

Esse projeto foi desenvolvido para **uso pessoal** e também como forma de praticar desenvolvimento web e criação de aplicativos.
